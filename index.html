ขั้นตอนที่ 1: สร้าง Google Sheet

1. เปิด sheets.google.com แล้วสร้าง Spreadsheet ใหม่
2. ตั้งชื่อ เช่น "Room Reservation"
3. คลิก Extensions → Apps Script
4. ลบโค้ดเดิมออกทั้งหมด แล้วไปขั้นตอนถัดไป

📊 เปิด Google Sheets

ขั้นตอนที่ 2: วาง Script และ Deploy

1. คัดลอกโค้ดด้านล่าง → วางใน Apps Script
2. กด Save (Ctrl+S)
3. คลิก Run → getSheet เพื่อ Authorize
4. Deploy → New deployment → Web app
5. Execute as: Me · Who has access: Anyone
6. กด Deploy แล้วคัดลอก URL ที่ได้
